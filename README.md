## 어떤 서비스인가요

첫 자취를 준비하거나 이사를 앞둔 청년은 매물 정보, 관리비, 계약 서류, 이사 일정, 신고 기한을 여러 곳에서 따로 확인해야 합니다. MOVE AGENT는 사용자가 말한 예산·조건·계약 정보·일정을 **내 이사 노트**에 저장하고, 단계가 바뀌어도 그 기록을 이어서 활용해 **지금 해야 할 다음 행동**을 안내합니다.

| 핵심 기능 | 하는 일 |
|---|---|
| 맞춤형 집 비교 | 예산·통학·선호 조건으로 후보를 비교하고, 교통비·보증금 이자까지 더한 실제 부담을 계산 |
| 계약 준비·정보 확인 | 건축물대장 조회로 용도·다가구 신호를 확인하고, 미확인 서류와 중개사에게 보낼 질문을 정리 |
| 상황 기반 일정 관리 | 이사일이 바뀌면 영향을 받는 할 일만 다시 계산하고, 신고 기한과 청년 주거지원 정보를 안내 |
| 주거 기록 관리 | 입주 때 남긴 사진·메모를 퇴거할 때 다시 찾아 비교 |
